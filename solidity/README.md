## OpenLeaf


## Usage


### Setup

```shell
$ forge install
```


## Testing 

```shell
$ forge test
```

### Local Deployment

```shell
$ anvil
```

### Deploy

```shell
$ forge script script/Counter.s.sol:CounterScript --rpc-url <your_rpc_url> --private-key <your_private_key>
```

### Cast

```shell
$ cast <subcommand>
```

### Help

```shell
$ forge --help
$ anvil --help
$ cast --help
```
